# DevUtils

All-in-one toolbox for developers — formatting, encoding, conversion, and more. **No external app required.**

This extension provides 40+ developer utilities directly inline:

## Tools

### Encoding / Decoding
- **Base64 String Encode/Decode** — Encode or decode Base64 text
- **Base64 Image Encode/Decode** — Work with Base64-encoded images
- **URL Encode/Decode** — Encode or decode URL strings
- **HTML Entity Encode/Decode** — Escape or unescape HTML entities
- **Backslash Escape/Unescape** — Escape/unescape backslashes and special chars

### Formatting
- **JSON Format/Validate** — Format or minify JSON
- **JS Beautify/Minify** — Format JavaScript with prettier
- **CSS Beautify/Minify** — Format CSS
- **SCSS Beautify/Minify** — Format SCSS
- **LESS Beautify/Minify** — Format LESS
- **HTML Beautify/Minify** — Format HTML
- **XML Beautify/Minify** — Format XML
- **SQL Formatter** — Format SQL queries
- **ERB Beautify/Minify** — Format ERB templates

### Conversion
- **CSV to JSON** — Convert CSV data to JSON
- **JSON to CSV** — Convert JSON to CSV
- **JSON to YAML** — Convert JSON to YAML
- **YAML to JSON** — Convert YAML to JSON
- **JSON to PHP Array** — Convert JSON to PHP array syntax
- **PHP Array to JSON** — Convert PHP array to JSON
- **PHP Serializer** — Serialize to PHP format
- **PHP Unserializer** — Unserialize PHP data to JSON
- **HTML to JSX** — Convert HTML to JSX/React
- **Number Base Converter** — Convert between decimal, hex, binary, octal
- **String Case Converter** — Convert between camelCase, snake_case, etc.

### Utilities
- **Hash Generator** — Generate MD5, SHA1, SHA256, SHA512 hashes
- **JWT Debugger** — Decode and inspect JWT tokens
- **UUID/ULID Generator** — Generate UUIDs and ULIDs
- **Lorem Ipsum Generator** — Generate placeholder text
- **Random String Generator** — Generate passwords and random strings
- **String Inspector** — Analyze string length, words, characters, encoding
- **Unix Time Converter** — Convert Unix timestamps to/from dates
- **URL Parser** — Parse and inspect URL components
- **Cron Parser** — Parse cron job expressions
- **Color Converter** — Convert between HEX, RGB, HSL
- **QR Code Generator** — Generate QR codes from text
- **RegExp Tester** — Test regular expressions interactively
- **Text Diff Checker** — Compare two texts and find differences

### Preview
- **Markdown Preview** — Preview markdown from clipboard
- **HTML Preview** — View HTML source from clipboard

### Auto Detect
- **Auto Detect** — Automatically detect clipboard content type and suggest the best tool

## Usage

Most commands work with your clipboard:
1. Copy some text to your clipboard
2. Run the desired command via Raycast
3. The result is automatically copied back to your clipboard

Interactive tools (Form-based) let you configure options before processing.

## No External Dependencies

This extension is completely self-contained. It does **not** require the DevUtils macOS app.
